Welcome! This repository is for practising the open source workflow.

## How to contribute
1. Open an issue that describes the problem you found.
2. Comment on the issue that you want to work on it and wait for the
   maintainer to assign it to you.
3. Fork this repository and create a new branch (never work on main).
4. Make a small, focused change.
5. Commit with a clear message and a sign-off (git commit -s).
6. Push the branch to your fork and open a Pull Request that says
   "Fixes #<issue number>".
7. If your pull request shows conflicts, update your branch from the
   upstream main branch and resolve them yourself.
8. Respond politely to review comments.

## Rules
- One Pull Request = one change.
- Do not add phone numbers, emails or other personal details.
- Be respectful in every comment.
